# Demo Script — StoryForge 94

*Estimated time: 8–10 minutes*

---

## Scene 1: Cold Start — Empty State (1 min)

**Action**: Open http://localhost:5173 in browser

**Say**:
> "We're looking at StoryForge 94 — a Product Narrative Studio. Before any events flow in, notice the empty state. Three event streams are about to activate: Infrastructure, Product deployments, and User Behavior signals."

**Show**: The empty state animation with three source badges.

---

## Scene 2: Events Start Flowing — Loading → Success (1 min)

**Action**: Events will auto-appear within 1–2 seconds.

**Say**:
> "The simulator is now emitting events from all three streams simultaneously. Watch the feed — events arrive ranked by our AI scoring engine, not by time of arrival."

**Point out**:
- Stats bar updating (total count, P1 count)
- Events appearing at top with priority badges
- Score bars (longer = higher priority)
- Color-coded priority left-border

---

## Scene 3: Walk the Narrative Feed (2 min)

**Action**: Scroll through the feed. Point to different priority events.

**Say**:
> "Each card contains a plain-English narrative generated by our NLG engine. The operator doesn't need to parse raw JSON or alert codes — they immediately know WHAT happened, WHERE, and HOW MANY users are affected."

**Click a P1 event**:
> "Let's drill into this critical event…"

---

## Scene 4: Event Detail Panel (1.5 min)

**Action**: Click a P1 (red) event to open detail panel.

**Show**:
- Narrative (repeat the story)
- Score breakdown bars → "Here's WHY it scored P1"
- Metadata grid (service, region, severity, users)
- Audit trail → "Every processing step is logged: received → scored → ranked → narrative generated"

**Say**:
> "Full traceability. Every triage decision is auditable."

---

## Scene 5: Filtering (30 sec)

**Action**: Click P1 filter button, then "⚙️ Infra" filter.

**Say**:
> "Operators can instantly focus. Show me only critical infrastructure events. The filter is client-side — zero latency."

---

## Scene 6: Operator Feedback Loop — BONUS (2 min)

**Action**: Open the Weight Adjuster panel (right sidebar).

**Say**:
> "Now the differentiator. Operators can tune HOW events are ranked in real-time, without a code deploy."

**Demo**:
1. Drag **User Impact** to 55% (slider auto-adjusts others)
2. Click **Apply Weights**
3. Watch feed re-rank — user-impact-heavy events bubble up

> "This is the feedback loop. If the ops team decides revenue impact matters more than raw latency spikes, they adjust in the UI, and the ranking adapts instantly."

**Reset**: Click reset button.

---

## Scene 7: Error State & Recovery (30 sec)

**Action**: Stop the server process momentarily.

**Show**: 
- Connection status changes to "Reconnecting…" (yellow)
- If connection drops: Error state appears

**Restart server**:
- Status returns to "Live" (green)
- SSE auto-reconnects, events resume

> "The system is resilient. Auto-reconnect with exponential backoff."

---

## Scene 8: Summary (30 sec)

**Say**:
> "In 6 hours, we built:
> - 3 live event stream ingestors
> - A weighted AI scoring engine with 4 dimensions
> - Template NLG for human-readable narratives
> - A real-time SSE operator dashboard
> - An operator feedback loop for live weight tuning
> - A full audit trail for every triage decision
> 
> StoryForge 94: from event chaos to prioritized narratives."

## Curl Commands for Live Demo

```bash
# Manual event injection
curl -X POST http://localhost:3001/api/events/ingest \
  -H "Content-Type: application/json" \
  -d '[{"source":"infrastructure","type":"service_down","severity":5,"region":"us-east-1","service":"payment-service","userImpact":75000,"metadata":{"health_check_failures":15}}]'

# Check ranked output
curl http://localhost:3001/api/events/history?limit=5

# View current weights
curl http://localhost:3001/api/config/weights
```
